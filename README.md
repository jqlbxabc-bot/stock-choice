# 动态选股系统 - 高频交易与10倍股筛选

## 系统简介

这是一个专为A股创业板高频交易者设计的动态选股系统，结合量化策略和10倍股潜力分析，提供实时股票筛选和投资建议。

## 主要功能

### 1. 高频交易选股（低吸潜伏策略）
- **选股条件**：振幅>3%，成交额>1.5亿，价格5-100元，涨跌幅-5%~+1%
- **评分标准**：振幅40% + 成交额30% + 涨跌幅20% + 价格10%
- **更新频率**：每10分钟（交易时间内）
- **适用场景**：日内回转交易，短线操作

### 2. 10倍股潜力筛选
- **六维筛选模型**：行业、市值、业绩、估值、技术、资金
- **重点行业**：人工智能、半导体、新能源、创新药、机器人、储能
- **更新频率**：每日收盘后
- **适用场景**：中长期投资布局

### 3. 行业轮动监控
- **监控指标**：行业资金流入、政策利好、景气度变化
- **轮动信号**：行业热度排名变化
- **更新频率**：每日

### 4. 风险控制系统
- **止损规则**：单票止损-8%，组合止损-15%
- **仓位控制**：单票最大仓位10%，单行业最大仓位20%
- **波动率控制**：根据市场波动调整仓位

## 安装与配置

### 系统要求
- Windows 10/11
- Python 3.12
- 网络连接（获取实时数据）

### 安装步骤

1. **下载系统**
   ```
   将整个"动态选股系统"文件夹复制到桌面
   ```

2. **配置Python路径**
   编辑`启动选股系统.bat`文件，修改第10行的Python路径：
   ```batch
   set PYTHON_PATH=你的Python路径
   ```

3. **安装依赖**
   首次运行会自动安装依赖包：
   - akshare（A股数据接口）
   - pandas（数据处理）
   - numpy（数值计算）

4. **运行系统**
   双击`启动选股系统.bat`文件

## 使用说明

### 基本使用
1. 双击`启动选股系统.bat`
2. 系统会自动获取实时数据
3. 根据当前时间执行相应策略：
   - 交易时间内（9:30-15:00）：执行高频交易选股
   - 非交易时间：执行10倍股潜力筛选
4. 查看输出结果和生成的文件

### 输出文件
- **JSON格式**：`output/高频交易第X轮_时间戳.json`
- **CSV格式**：`output/高频交易第X轮_时间戳.csv`
- **日志文件**：`logs/选股系统.log`

### 配置修改
编辑`config.yaml`文件可以调整：
- 选股参数（价格范围、振幅要求等）
- 评分权重
- 风险控制参数
- 系统设置

## 策略说明

### 高频交易策略（低吸潜伏）
**核心理念**：在股票回调时低吸，等待反弹获利

**选股逻辑**：
1. **振幅>3%**：确保有足够的波动空间
2. **成交额>1.5亿**：确保流动性充足
3. **涨跌幅-5%~+1%**：避免追高，寻找回调机会
4. **价格5-100元**：排除极端价格股票

**评分标准**：
- 振幅得分（40%）：振幅越大，得分越高
- 成交额得分（30%）：成交额越大，流动性越好
- 涨跌幅得分（20%）：越接近0%，得分越高
- 价格得分（10%）：中间价位得分最高

### 10倍股潜力筛选
**六维筛选模型**：
1. **行业维度**：国家战略支持的新兴产业
2. **市值维度**：当前市值<300亿元（优先<100亿）
3. **业绩维度**：近2年复合增长率>30%
4. **估值维度**：PEG<1.5
5. **技术维度**：处于上升趋势初期或底部反转
6. **资金维度**：机构资金开始关注或增持

## 注意事项

### 数据源说明
- 使用akshare获取A股实时数据
- 数据可能存在延迟（通常1-2分钟）
- 非交易时间使用缓存数据

### 风险提示
1. **市场风险**：A股市场波动性大，政策影响显著
2. **策略风险**：历史表现不代表未来收益
3. **技术风险**：数据源稳定性问题
4. **操作风险**：严格执行止损纪律

### 最佳实践
1. **交易时间**：建议在9:35后运行（数据稳定）
2. **多轮筛选**：每轮间隔5-10分钟，排除已推荐股票
3. **仓位控制**：单票仓位不超过10%
4. **止损执行**：严格设置止损位

## 常见问题

### Q1: 系统无法启动
A: 检查Python路径是否正确，确保已安装Python 3.12

### Q2: 数据获取失败
A: 检查网络连接，确保可以访问akshare数据源

### Q3: 没有找到股票
A: 可能当前市场条件不符合选股标准，尝试调整config.yaml中的参数

### Q4: 如何添加排除股票
A: 编辑`excluded_stocks.json`文件，添加要排除的股票代码
